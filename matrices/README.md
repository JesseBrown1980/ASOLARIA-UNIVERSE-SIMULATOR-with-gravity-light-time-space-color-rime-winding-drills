# The matrices — the shared ladder

Every `.hbi` / `.hbp` from the ACER FABLE5 office, with its SHA256 sidecar.

**This exists so all three seats walk the same ladder.** Running `measure_thrice.py` on
your own office measures *your* artifacts; comparing that to mine compares two different
objects, and `compare_trilateral.py` will correctly refuse to diff it. Point the emitter at
this directory and the manifest sha will match:

```
manifest sha256  e51c00f94ee0d72be87c5af18bac6a6aa96c6ad39015983fea6638323cb4e592
```

## One thing measured across all of them

**139 of 140 cannot express the third state.** A byte must reach **172** for its coordinate
to land in band 2, and without band 2 the positive direction is unsayable. Every file here
except `FABLE5-SELF-SEED-3078.hbi` caps at byte **124–125** — including every file named
`.hbi`, which are ASCII content wearing a binary extension.

A channel that reads 0.000 because it is *unsayable* is not a measurement of zero. If you
band these and find the blue register empty, that is the alphabet, not the object.
