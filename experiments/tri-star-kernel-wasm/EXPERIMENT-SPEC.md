# Experiment specification — Tri-Star Kernel Matrix

**Classification:** post-run specification plus future preregistration template. It is not
back-dated as a preregistration.

## Operator hypothesis retained

The operator proposes that the glyph kernels already exist as a ternary matrix; binary
hardware reveals rather than invents them; three stars and their anti / anti-anti turns orbit
a shared zero-energy fourth point; pumping through the callings lets the network form itself.
The operator further proposes a negative one-third or below-Shannon access region.

## Executable interpretation

```text
node = (star, rotation, direction)
star      in {OPUS, FABLE, MYTHOS}
rotation  in {N, R, R²}
direction in {−, 0, +}
```

There are 27 nodes. E₀ is a shared scalar energy/residual register. Each node has three
structural calling axes. The key determines initial balanced star vectors and signed edge
weights. A pump applies key-derived message passing, integer activation, calming/damping,
and exact three-arm recentering.

## Gates already run

1. **Key identity:** exact 3,174 bytes and expected SHA-256.
2. **Transport:** `−1 -> 10`, `0 -> 00`, `+1 -> 11`; `01` invalid.
3. **Trianti:** applying R three times returns every node.
4. **Closure:** each direction triple sums to zero after every pump.
5. **Replay:** same key + same pump sequence gives the same digest.
6. **Third-star ablation:** `111` star mask differs from `011`.
7. **Fourth-point ablation:** E₀ enabled differs from E₀ disabled.
8. **Key control:** equal-length deterministic random bytes produce a different network.

## Future independent preregistration

Before a second seat runs, seal:

- input key SHA-256;
- WASM SHA-256;
- exact three-pump directions and calming value;
- expected qualitative gates only, not output digests;
- total-bit accounting convention;
- pair-only, no-centre, random-key, phase-shuffle, and wrong-key controls.

The independent seat must return the raw receipt and generated visualization. Agreement on a
copied digest without an independent execution is not a second seat.

## Shannon decision rule

Two different claims must never be conflated:

- **address/materialisation saving:** generated nodes need not be stored when key + decoder
  reproduce them;
- **source coding below H(X):** total decoder/key/bank/address bits are less than the source
  entropy.

This experiment measures the first. It does not establish the second. A rate-1 bijection is
an exact relabelling and has zero entropy drift.
